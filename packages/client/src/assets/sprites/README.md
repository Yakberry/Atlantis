# Спрайты

Файлы здесь подхватываются автоматически: достаточно заменить пустой файл нарисованным (с тем же именем)
и перезагрузить страницу. Пока файл пустой, битый или отсутствует, игра рисует запасной вариант:
плоскую заливку для локаций, цветные фигуры для юнитов и цветные квадраты для ресурсов.

## `tiles/` — локации (PNG, прозрачный фон)

| Файл | Что это |
|---|---|
| `food.png`, `wood.png`, `marble.png`, `copper.png` | локации с ресурсом: продовольствие, лес, мрамор, медь |
| `unexplored.png` | суша, которую видно, но её ресурс ещё никто не изведал |
| `fog.png` | локация вне поля зрения («туман») |
| `sea.png` | море: окружает остров и заполняет его заливы (видно как море сразу, без изведывания) |

Гекс острой вершиной вверх. Размер **222 × 256 px** (пропорция √3 : 2), гекс упирается в края картинки.
Игра обрезает картинку по контуру гекса и сама рисует поверх неё границу цвета владельца,
поэтому по краю ничего важного не рисуйте.

Игрок может включить «Упрощённую графику локаций» (под кнопкой выхода из комнаты):
тогда картинки локаций не используются, а рисуется плоская заливка. Настройка хранится на устройстве игрока.

## `resources/` — иконки ресурсов (SVG, цветные)

`food.svg`, `wood.svg`, `marble.svg`, `copper.svg`. Квадрат (`viewBox="0 0 64 64"`), читаются на высоте 16–24 px.
Показываются в панели запасов и рядом с всплывающей цифрой добычи.

## `units/` — юнит и постройки на карте (SVG, одноцветные)

`unit.svg`, `colony.svg`, `fortified_colony.svg` (укреплённая колония). Квадрат (`viewBox="0 0 64 64"`), любая одна заливка и прозрачный фон.
Игра красит иконку в цвет игрока по её форме (по прозрачности), поэтому цвет в файле значения не имеет,
а градиенты и полупрозрачность превратятся в одноцветную заливку с той же прозрачностью.
Иконка рисуется на тёмной подложке-кружке, так что на любой текстуре локации она видна.

## `buildings/` — карточки построек в меню строительства (SVG, цветные)

`colony.svg`, `fortified_colony.svg`, `road.svg`. Квадрат (`viewBox="0 0 64 64"`), показываются на карточке высотой около 40 px.
Это иллюстрации карточек; на самой карте колонии рисуются иконками из `units/`, а дороги — линиями цвета игрока.
